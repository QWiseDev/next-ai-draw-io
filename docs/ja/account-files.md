# アカウントファイル

既定では、アプリは図をブラウザーに保存します。アカウントモードを有効にすると、図は自分のサーバーに保存され、同じユーザーは別のデバイスからも開けます。

## 有効にする

次を設定します：

```bash
ACCOUNT_MODE=true
```

サーバーはアカウント、ログインセッション、ファイルを SQLite データベースの `data/accounts.db` に保存します。別の場所にするには `ACCOUNT_DB_PATH` を設定します。Docker Compose は `./data` を `/app/data` にマウントするため、コンテナーを入れ替えてもデータベースは残ります。

この変数を設定しない場合、アカウントモードは無効です。通常の匿名アプリとブラウザー保存の動作は変わりません。

## ユーザーを作成する

`ADMIN_PASSWORD` を設定し、`/admin` を開いて管理者としてサインインします。そのページのブラウザーコンソールからアカウント API を呼び出せます：

```js
await fetch("/api/admin/accounts", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "x-admin-password": "管理者パスワード",
    },
    body: JSON.stringify({
        username: "alice",
        password: "長いパスワード",
    }),
})
```

公開サインアップはありません。ユーザー名は 3〜32 文字の英数字、ドット、アンダースコア、ハイフンです。パスワードは 10 文字以上にしてください。

## ファイルセンター

`/login` でサインインし、`/files` を開きます。センターには次があります：

-   最近のファイル
-   マイファイル（フォルダー対応）
-   復元や完全削除ができるゴミ箱
-   検索、並べ替え、グリッド/リスト表示
-   名前の変更、移動、削除
-   匿名アプリから一度だけ移行する「ブラウザーのファイルをインポート」

エディターは図、会話、サムネイル、バージョン履歴を自動保存します。別のデバイスが同じファイルを先に保存した場合、このデバイスの変更は競合コピーとして保存され、上書きしません。
